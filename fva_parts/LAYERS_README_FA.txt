مسیر:
  analyze_text -> clean_text + SmartTextEditor (ویراستار)
  -> ماسک کلیدی‌ها -> CANINE و واژه‌نامه هر دو پیشنهاد می‌دهند
  -> تصمیم کلمه‌به‌کلمه + گزارش -> امضا (Handshake)
  -> باز کردن ماسک با تلفظ ثابت -> add_prosody -> build_ssml (یک بار)
  -> edge_engine.generate_voice (Farid, -11%, -8Hz, is_ssml=True)

قاعده‌های مذاکره برای هر کلمه:
  1. کلمه کلیدی      -> دست‌نخورده، لایه ۲ تلفظ ثابت می‌گذارد
  2. اعراب دستی      -> برنده (کشف ۱)
  3. در واژه‌نامه    -> واژه‌نامه برنده، CANINE اعراب دوبل نمی‌گذارد
  4. فقط CANINE      -> قبول، مگر حروف را عوض کند یا اعراب متناقض بدهد
  5. هیچ‌کدام        -> کلمه اصلی
هر تصمیم با schema گزارش OCR ثبت می‌شود:
  stage, where, kind, original, suggestion, confidence
